# Tabela oficial de códigos de despacho — Marcas (INPI)

Fonte: tabela oficial do INPI (WEBSEEK Anterioridade, https://revistas.inpi.gov.br/rpi/download/despachos/300),
fornecida pela usuária em 23/07/2026. Referência para classificar códigos de despacho novos que
aparecerem em futuras importações de RPI, antes de propor uma regra em `/dispatch-rules` para
confirmação do administrador (o sistema nunca classifica sozinho — ver seção 7 do projeto).

Prazo de manifestação/recurso, quando explícito no texto oficial, geralmente é de 60 dias corridos
contados da publicação na RPI, salvo indicação em contrário (ex.: exigência formal = 5 dias).

## Observações

- Categorias disponíveis no sistema (enum `DispatchCategory`): DEFERIMENTO, PUBLICACAO, OPOSICAO,
  NULIDADE, CADUCIDADE, INDEFERIMENTO, ARQUIVAMENTO, OUTROS_NAO_CLASSIFICADO.
- Vários despachos (ex.: "Exigência formal", "Exigência de mérito") não mapeiam bem para nenhuma
  categoria fixa — usar OUTROS_NAO_CLASSIFICADO com subcategoria descritiva, ou perguntar à usuária
  como ela prefere tratar esses casos (podem merecer uma categoria própria no futuro).
- "Concessão de registro" (I158, I400-numérico, I768/I770 em Madri) não tem categoria própria — está
  sendo tratada como DEFERIMENTO com subcategoria "Concessão de Registro", a confirmar com a usuária.
- Tabela completa (34 páginas, ~300 códigos) foi lida integralmente da fonte oficial; este arquivo
  lista os códigos mais prováveis de aparecer em uma RPI de marcas comum. Para um código raro que não
  esteja aqui, seria necessário pedir à usuária o PDF novamente ou consultar
  https://revistas.inpi.gov.br/rpi/download/despachos/300 diretamente (bloqueado para acesso
  automatizado a partir do ambiente de desenvolvimento).
